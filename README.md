# Пульт 1.12.0

Настольная студия инструментов для Windows 11. Это не одна кнопка «сделай красиво», а набор локальных приложений для изображений, данных, текста, документов и диагностики системы.

## Что умеет

### Стол изображений
- Пакетная конвертация PNG, JPEG, WebP, BMP, GIF и TIFF.
- Изменение ширины и высоты с сохранением пропорций, вписыванием или заполнением области.
- Поворот на 90/180/270°, отражение по горизонтали и вертикали.
- Чёрно-белый режим, изменение яркости, JPEG/WebP качество и текстовый водяной знак.
- Контактный лист для целой пачки фотографий.
- Информация о формате, разрешении, числе кадров, мегапикселях и размере файла.

### Данные и архивы
- Проверка JSON с сообщением о строке и столбце ошибки, форматирование и минификация.
- JSON ↔ CSV, JSON ↔ XML; вложенные значения JSON сохраняются в ячейках как JSON-текст.
- Автоматическое определение разделителя CSV: запятая, точка с запятой, табуляция или вертикальная черта.
- Перекодировка UTF-8, Windows-1251, CP866, KOI8-R и других доступных Python кодировок.
- Упаковка папок в ZIP, просмотр состава и размеров архива.
- Безопасная распаковка: проверка абсолютных и выходящих за папку путей, Windows-путей, символических ссылок, количества файлов, суммарного размера и экстремальной степени сжатия.

### Редакторы текста
- Открытие и сохранение TXT, Markdown, HTML, JSON, CSV, XML, Python, JavaScript, CSS, YAML, логов и других текстовых файлов.
- Статистика слов, символов, строк, абзацев и примерного времени чтения.
- Поиск и замена, регулярные выражения, поиск без учёта регистра.
- Преобразование регистра, очистка пробелов, нормализация переносов, удаление пустых и повторяющихся строк, сортировка строк.
- Сравнение двух файлов с unified diff.
- Экспорт Markdown в самостоятельный HTML с заголовками, списками, цитатами, ссылками, форматированием и блоками кода.
- Markdown HTML-экранируется; опасные схемы ссылок блокируются.

### Пульт Office 1.11

Локальная офисная рабочая область с редакторами Word, Excel и PowerPoint. Движки основаны на готовых библиотеках **python-docx**, **openpyxl** и **python-pptx**.

**Word — DOCX**
- Заголовки, абзацы, маркированные и нумерованные списки, цитаты, блоки кода, разделители.
- Жирный, курсив, зачёркивание, ссылки HTTP/HTTPS и mailto с проверкой схемы.
- Настоящие таблицы Word из Markdown-таблиц, встроенные изображения, подписи и разрывы страниц.
- Поиск и замена, автор и свойства документа, A4/Letter, книжная и альбомная ориентация, номер страницы в колонтитуле.
- При открытии извлекаются встроенные изображения во временный кэш; при сохранении они повторно встраиваются в DOCX.
- При редактировании исходного файла используется его шаблон: сохраняются стили документа, тема, параметры секции, колонтитулы и шапка. Основной текст, таблицы и поддерживаемые объекты пересобираются из редактора.

**Excel — XLSX/XLSM**
- Сетка листа с редактированием по двойному щелчку и строкой формул/значения.
- Копирование и вставка прямоугольных диапазонов через буфер обмена TSV.
- Создание, переименование и удаление листов; вставка и удаление строк и столбцов.
- Форматирование жирным, числовые форматы, заливки, автофильтр, закрепление области и автоширина.
- Структурированные таблицы Excel, диаграммы, условные цветовые шкалы и полосы данных, выпадающие списки проверки данных.
- Поиск и замена по всем листам, импорт CSV с определением кодировки и разделителя, экспорт листа в CSV.
- Сохранение XLSX и XLSM; VBA-контейнер сохраняется при работе с XLSM. В формулах выставляется автоматический пересчёт при открытии книги в Excel/LibreOffice.

**PowerPoint — PPTX**
- Создание презентаций с титульным слайдом; добавление, удаление, перестановка слайдов.
- Заголовки и текстовые блоки, списки, заметки докладчика.
- Добавление изображений и таблиц на слайд.
- При редактировании существующего PPTX используется исходная презентация: нетронутые изображения, диаграммы, фигуры, фон, тема и макеты сохраняются; можно менять текстовые заполнители, заметки, порядок слайдов и добавлять новые.

**Форматы и PDF**
- Через установленный LibreOffice доступны экспорт PDF и конвертация DOC/DOCX, XLS/XLSX, PPT/PPTX, ODT/ODS/ODP.
- Встроенные редакторы DOCX, XLSX/XLSM и PPTX не требуют Microsoft Office или LibreOffice.
- Все операции выполняются локально.

**Ограничения совместимости:** Пульт Office пока не является полной заменой настольного Microsoft Office. openpyxl не пересчитывает формулы самостоятельно и не сохраняет все редкие функции Excel (например, некоторые типы сводных кешей и внешние расширения). При пересборке тела DOCX могут упрощаться плавающие текстовые блоки, SmartArt и OLE-объекты. python-pptx умеет сохранять многие существующие объекты, но не реализует весь редакторский стек PowerPoint, например полноценную анимацию и переходы. Для сложной авторской вёрстки предусмотрено открытие исходного файла во внешнем приложении; PDF и старые форматы требуют LibreOffice.

### Универсальный инфракрасный пульт 1.12

Локальные профили пультов для телевизоров, кондиционеров, ТВ-приставок, проекторов, аудиосистем, ресиверов, вентиляторов и световых контроллеров.

**Подключение адаптеров**
- Broadlink RM Mini / RM4 Mini / RM Pro — локальное обнаружение, отправка ИК-команд и обучение с оригинального пульта. Работает через готовую библиотеку python-broadlink.
- USB-ИК через COM-порт — ESP32 с ИК-светодиодом и приёмником. В репозитории есть прошивка firmware/PulpitIRBridge.ino на базе IRremoteESP8266.
- Home Assistant — отправка и обучение именованных команд через remote.send_command / remote.learn_command; подходит для настроенных Broadlink, ESPHome и других remote-интеграций.

**Форматы и профили**
- Импорт Flipper Zero .ir с raw-сигналами и parsed-кодами NEC, NECext, Samsung32 и Sony SIRC.
- Импорт learned Pronto HEX (формат 0000).
- Обучение команды наведением штатного пульта на Broadlink или USB-ИК приёмник.
- Экспорт профиля в .ir для Flipper Zero и совместимых устройств.
- Несколько именованных пультов с категорией, брендом, моделью и набором кнопок. Профили сохраняются локально в %APPDATA%/Pulpit/infrared/profiles.json.
- Долгосрочный токен Home Assistant используется только в памяти текущего сеанса и не сохраняется в профилях.

**USB-ИК прошивка**
- Arduino IDE + ESP32 board support.
- Установи библиотеку IRremoteESP8266 через Library Manager.
- Передатчик через транзисторный драйвер на GPIO 4; демодулирующий ИК-приёмник 38 кГц (например TSOP38238/VS1838B) на GPIO 15.
- Прошей скетч, подключи устройство по USB и выбери соответствующий COM-порт в Пульте.

**Важные границы:** ноутбук без ИК-передатчика не может излучать команды сам по себе. Нужен Broadlink или USB-ИК адаптер; для Home Assistant — заранее настроенный IR-адаптер и сущность remote.*. ИК требует прямой видимости приёмника и не проходит через стены. Bluetooth-, Wi-Fi- и RF-пульты не становятся инфракрасными; для них нужен соответствующий сетевой или RF-адаптер. Некоторые кондиционеры используют длинные фирменные кадры, а динамические и защищённые протоколы могут не поддерживаться.

Полезные источники:
- Flipper IR format: https://developer.flipper.net/flipperzero/doxygen/infrared_file_format.html
- Flipper-IRDB: https://github.com/flipperdevices/IRDB
- ESPHome transmitter: https://esphome.io/components/remote_transmitter/
- Home Assistant Remote: https://www.home-assistant.io/integrations/remote/

### Единицы измерения
- Длина, масса, площадь, объём, скорость, время, энергия, давление, температура и объём данных.
- Метрические и распространённые имперские единицы, десятичные и двоичные единицы хранения.
- Можно получить конвертацию сразу во все единицы выбранной категории.

### Система и диагностика
- Версия ОС, архитектура и процессор.
- Логические ядра и текущая загрузка CPU.
- Общая и доступная RAM.
- Общий, занятый и свободный объём системного диска.
- Батарея и время после запуска системы, если это предоставляет ОС.
- Для мониторинга используется psutil. Отчёт не собирает IP-адреса, серийные номера и пользовательские файлы.

## Конструктор страниц

В приложении остаётся визуальный конструктор GrapesJS с drag-and-drop, слоями, стилями, SEO, медиатекой, адаптивными режимами, многостраничностью и экспортом сайта в ZIP. Изменения версии 1.9.0 не меняют его формат проектов и UI.

Полные возможности редактора GrapesJS загружаются с закреплённой версии CDN; при недоступности CDN сохраняется ограниченный автономный режим.

## Запуск на Windows 11

Требуется Python 3.10 или новее.

~~~bat
run.bat
~~~

Или вручную:

~~~bat
python -m pip install -r requirements.txt
python main.py
~~~

Для конструктора требуется Microsoft Edge WebView2 Runtime. В Windows 11 он обычно уже установлен вместе с Edge.

## Проверки и сборка

~~~bat
python -m pip install -r requirements.txt pytest
python -m pytest tests
~~~

GitHub Actions на windows-latest собирает Pulpit.exe через PyInstaller и упаковку установщика Inno Setup. Артефакты находятся в Actions:

https://github.com/ivanivorontsov-sudo/pulpit-os/actions
