# Пульт

Настольная студия инструментов для Windows 11: конвертеры изображений и данных, текстовые редакторы, создание документов Office и полноценный визуальный конструктор сайтов.

## Главное — визуальная студия сайтов

Откройте в приложении **«Конструктор страниц»**. Он запускается в отдельном нативном окне на WebView2 и использует GrapesJS 0.23.9 — открытый визуальный редактор с drag-and-drop, слоями, стилями, свойствами и живым предпросмотром.

Возможности конструктора:

- Перетаскивание секций и блоков на страницу; редактирование текста прямо на холсте.
- Библиотека блоков: первый экран, секции, контейнеры, колонки, навигация, подвал, заголовки, текст, списки, кнопки, изображения, галереи, видео, карты, карточки, преимущества, FAQ, формы, тарифы, отзывы, контакты, таблицы и другие элементы.
- Панели слоёв, стилей CSS и свойств HTML-элементов.
- Многостраничные проекты: создание, переименование, выбор и удаление страниц.
- Отдельные SEO-заголовок, описание и адрес страницы.
- Переключение предпросмотра Desktop / Tablet / Mobile.
- Медиатека: изображения копируются в папку проекта; их можно использовать повторно.
- Готовые основы: лендинг, портфолио, сайт компании, блог и каталог. Все блоки и тексты редактируются.
- Редактор HTML/CSS, отмена и повтор действий, автосохранение и ручное сохранение JSON-проекта.
- Проверка основных SEO- и доступностных ошибок: H1, alt, ссылки, кнопки, описание и иерархия заголовков.
- Экспорт ZIP: многостраничный статический сайт, HTML, CSS, JavaScript и изображения — готов к размещению на GitHub Pages или другом статическом хостинге.
- Старые проекты Пульта с деревом блоков автоматически переводятся в новый формат при открытии.

**Приватность:** проект и изображения хранятся локально. Аккаунт, серверная база данных и облачная подписка не нужны. При наличии интернета используется закреплённая версия библиотеки GrapesJS с jsDelivr; если CDN недоступен, открывается автономный режим с редактированием HTML на холсте и добавлением блоков.

## Другие инструменты

- Стол картинок: пакетная конвертация изображений, формат и размер результата.
- Данные и архивы: JSON ↔ CSV, упаковка папки в ZIP.
- Редакторы: текст, Markdown, статистика текста, уменьшение изображений.
- Office: создание и чтение DOCX, XLSX, PPTX через Open XML; Microsoft Office для создания файлов не обязателен.
- Единицы измерения: длина, масса и температура.
- Система: сведения о Windows и Python.

## Запуск на Windows 11

Требуется Python 3.10 или новее.

~~~bat
run.bat
~~~

Или вручную:

~~~bat
python -m pip install -r requirements.txt
python main.py
~~~

Для визуального конструктора требуется Microsoft Edge WebView2 Runtime. В Windows 11 он обычно уже установлен вместе с Edge; если окно конструктора не запускается, установите WebView2 Runtime с официальной страницы Microsoft. Визуальный редактор может работать без доступа к CDN в автономном режиме.

## Проверки и сборка

~~~bat
python -m pip install -r requirements.txt pytest
python -m pytest tests
~~~
